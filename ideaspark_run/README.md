# ideaspark_run

Run directory of the ResearchStudio IdeaSpark skill (Stage 1: idea generation and prior-art collision checks).

The retrieved third-party paper texts (full texts in `phase0/fulltext/`, `phase0/fulltext_cache.json`) and the
retrieval/collision records that contain paper abstracts (`phase0/*_phase0.json`, `phase0/lit_results.json`,
`phase2_generate/closest_abstracts.json`, `phase3_collision/*collision*.json`, `phase3_revise/collision/*collision*.json`
and the `.*_channel_hits.json` files) are **not redistributed** in this repository; they were kept locally only.
The run's own outputs (idea candidate, critique, revision, receipts) and the literature table (`phase0/lit_table.md`,
titles and metadata only) remain.
